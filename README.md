## Concrete Dreams — Skate Plaza

A small, self-contained 3D skateboarding game built with Three.js. Open `index.html` in a modern browser while connected to the internet (Three.js is loaded from jsDelivr), or serve the project locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Controls

- **WASD** or **arrow keys** — steer and ride
- **Space** — ollie
- **Left / right arrow** — perform tricks while airborne
- **Shift** — push for speed
- **R** — reset your line

Land tricks to bank points, or grind the plaza rails to build a combo. Touch-friendly controls are available on small screens.
